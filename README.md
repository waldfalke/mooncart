# Prosumer

Скилл Codex для переноса выбранного товара или корзины из магазина в форму посредника:

`магазин -> order-draft.json -> форма посредника`

Модель читает выбранный товар или корзину через Playwright, сохраняет размеры, цвета, количества,
цены и валюту в JSON, затем заполняет ими форму посредника. Можно закрыть браузер и продолжить
позже. Если данных не хватает или цена изменилась, скилл сообщает об этом.

После заполнения скилл сверяет значения формы и останавливается. Он не отправляет заявки,
не оформляет и не оплачивает заказы, не принимает оферту. Магазин, посредника, маршрут и товар
выбирает пользователь.

## Установка

Нужны Codex, Python и установленный скилл `playwright` для управления браузером.
Вход в магазин или кабинет посредника пользователь выполняет сам в браузере.

Скачайте репозиторий и установите Python-зависимость в окружение, которым пользуется агент:

```sh
git clone https://github.com/waldfalke/prosumer.git
cd prosumer
python -m pip install -r requirements.txt
```

Разместите папку `prosumer` в своём каталоге skills Codex (обычно `~/.codex/skills/`, либо
`skills/` внутри настроенного `CODEX_HOME`). Playwright устанавливается отдельно.

## Примеры запросов

- «Сохрани выбранный товар, чтобы завтра перенести его посреднику».
- «Сохрани всю корзину, не потеряв размеры и цвета».
- «Продолжи сессию `<session-id>` и подготовь выбранную форму, без отправки».

Данные товара сохраняются в `stand/<session-id>/order-draft.json`. Пароли, cookies,
платёжные реквизиты и личные адреса в этот файл не записываются.

## Проверки

Из корня репозитория, после установки зависимости:

```sh
python evals/schema/validate.py
python evals/validator/validate_semantics.py
python scripts/validate_order_draft.py evals/schema/valid-order-draft.json
```

Сценарии и результаты находятся в [evals](evals/). Эти команды проверяют файл данных,
а не текущую работу сайтов. Живой перенос проверен для одной позиции и формы СДЭК, без отправки.
