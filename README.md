# Prosumer

Скилл Codex для переноса выбранного товара или корзины из магазина в форму посредника:

`магазин -> order-draft.json -> форма посредника`

Модель работает через Playwright. JSON сохраняет наблюдённые варианты, количества, цены, валюту,
источники и пробелы между сессиями. Validator проверяет локальный контракт, но не читает сайт и
не подтверждает актуальность цены. Кэш локаторов партнёра ускоряет поиск полей, не заменяя их проверку.

Скилл останавливается после заполнения и read-back. Он не отправляет заявки, не оформляет и не
оплачивает заказы, не принимает оферту. Магазин, посредника, маршрут и товар выбирает пользователь.

## Установка

Нужны Codex, Python и доступный скилл `playwright` для управления браузером. Логин выполняется
пользователем в браузере; пароль не запрашивается и не сохраняется в draft.

Скачайте репозиторий и установите Python-зависимость в окружение, которым пользуется агент:

```sh
git clone https://github.com/waldfalke/prosumer.git
cd prosumer
python -m pip install -r requirements.txt
```

Разместите папку `prosumer` в своём каталоге skills Codex (обычно `~/.codex/skills/`, либо
`skills/` внутри настроенного `CODEX_HOME`). Можно установить репозиторий через `skill-installer`.
Playwright не входит в этот пакет: используйте установленный browser-control skill.

## Примеры запросов

- «Сохрани выбранный товар, чтобы завтра перенести его посреднику».
- «Сохрани всю корзину, не потеряв размеры и цвета».
- «Продолжи сессию `<session-id>` и подготовь выбранную форму, без отправки».

Рабочие данные создаются в `stand/<session-id>/order-draft.json`. `stand/`, браузерные снимки и
окружение Python исключены из Git. Личные данные, cookies, реквизиты и адреса не входят в draft.

## Проверки

Из корня репозитория, после установки зависимости:

```sh
python evals/schema/validate.py
python evals/validator/validate_semantics.py
python scripts/validate_order_draft.py evals/schema/valid-order-draft.json
```

Поведенческие сценарии и результаты находятся в [evals](evals/). Они различают синтетический replay
и живое наблюдение. Проверено несколько ограниченных проходов; совместимость с любым магазином,
актуальный DOM СДЭК, серверное принятие цены и полный checkout не гарантируются.
