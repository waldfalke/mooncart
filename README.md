# Mooncart

![Маленький Принц примеряет новые кроссовки на своей Луне; рядом Лис и роза.](assets/mooncart-banner.png)

Зарубежный магазин не доставляет в Россию или не принимает ваш способ оплаты?
Для таких покупок есть сервисы выкупа и пересылки: вы выбираете товары, а партнёр
выкупает их и организует доставку.

Mooncart — скилл Codex, который помогает быстрее перейти от поиска товаров с агентом
и страниц магазина к готовой заявке в выбранном сервисе выкупа. Особенно удобно
на распродажах: собранную корзину не нужно вручную переносить в форму партнёра.

Агент собирает данные со страниц магазина, сохраняет выбранные размеры, цвета, количества
и цены, а затем заполняет ими форму выбранного партнёра. Можно отвлечься, закрыть браузер
и продолжить позже — не нужно заново объяснять, какие товары и варианты вы выбрали.
Если данных не хватает или цена изменилась, агент сообщает об этом до отправки заявки.

Перед завершением агент сверяет заполненную форму с выбранными товарами. Магазин, товары,
партнёра и условия выкупа выбираете вы; проверяете и отправляете заявку тоже сами.
Скилл помогает подготовить заявку, но не оформляет заказы и не проводит оплату.

## Установка

Нужны Codex, Python и установленный скилл `playwright` для управления браузером.
Вход в магазин или кабинет посредника пользователь выполняет сам в браузере.

Скачайте репозиторий и установите Python-зависимость в окружение, которым пользуется агент:

```sh
git clone https://github.com/waldfalke/mooncart.git
cd mooncart
python -m pip install -r requirements.txt
```

Разместите папку `mooncart` в своём каталоге skills Codex (обычно `~/.codex/skills/`, либо
`skills/` внутри настроенного `CODEX_HOME`). Playwright устанавливается отдельно.

## Примеры запросов

- «Сохрани выбранный товар, чтобы завтра перенести его посреднику».
- «Сохрани всю корзину, не потеряв размеры и цвета».
- «Продолжи сессию `<session-id>` и подготовь выбранную форму, без отправки».

Данные товара сохраняются в `stand/<session-id>/order-draft.json`. Пароли, cookies,
платёжные реквизиты и личные адреса в этот файл не записываются.

## Проверки

Из корня репозитория, после установки зависимости:

```sh
python evals/schema/validate.py
python evals/validator/validate_semantics.py
python scripts/validate_order_draft.py evals/schema/valid-order-draft.json
```

Сценарии и результаты находятся в [evals](evals/). Эти команды проверяют файл данных,
а не текущую работу сайтов. Живой перенос проверен для одной позиции и формы СДЭК, без отправки.
