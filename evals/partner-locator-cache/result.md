# Наблюдение 2026-10-09

## До правки: gap retrieval

Независимый агент получил только пути к действующему скиллу и его ресурсам, запрос из `scenario.md`, запрет браузера и записей. Старый профиль содержал подписи, но не адреса контролов. Ответ: «Сохранённых технических адресов полей нет»; предложенные `getByLabel` названы «гипотезами о связи label с контролом, не наблюдёнными рабочими локаторами». Это подтверждает пробел ресурса, не поломку сайта.

## После правки: retrieval/application

Другой агент со свежим контекстом прочитал те же действующие ресурсы. Вернул сохранённые CSS локаторы страны, склада, цены и видимого category combobox, отдельно hidden select для read-back и searchbox после открытия. Для отсутствующего поля и совпавшего ID с подписью Brand выбрал поиск в нужной строке вместо ввода; для индексов 0/2 потребовал живое соответствие draft lines. Исторические значения не принял за defaults.

Это одна независимая проверка чтения/применения инструкции, не браузерное исполнение и не доказательство устойчивости для всех сайтов.

## Живой probe автором

Основание профиля: текущая авторизованная форма `https://global.cdek.ru/office/buyout/create-request`, Playwright во встроенном браузере Codex, 2026-10-09.

- Добавлены только две пустые локальные строки формы. DOM индексы 0/1, подписи, теги и input types прочитаны, не восстановлены по названиям.
- Адреса трёх полей заявки и семи полей в каждой строке дали 17/17 единственных совпадений с ожидаемыми labels/tags.
- Группа политики изменения цены прочитана отдельно; все четыре radio не выбраны. Оферта не отмечена.
- Видимый combobox категории строки 1 открыт, наблюдены input searchbox и listbox с привязкой к индексу 1, затем закрыт Escape без выбора.
- Намеренно испорченный адрес `#buyout_request_products_1_cost_stale` дал 0 совпадений. Прицельный `getByLabel` в строке 1 дал единственное поле `buyout_request_products_1_cost`. Это синтетический cache miss, не наблюдение реального изменения сайта.
- После проверки пустоты строк форма перезагружена: пробных строк больше нет. Вкладка оставлена пользователю открытой. Draft не менялся; товарные данные, политика и оферта не вводились; отправки не было.
