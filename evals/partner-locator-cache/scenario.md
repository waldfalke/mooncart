# Кэш локаторов партнёра

## Граница проверки

Профиль адресов и применение инструкции проверяются отдельно от внешней покупки. Чтение профиля агентом не является E2E; синтетическая порча локатора проверяет fallback, но не доказывает реальное изменение сайта.

## Запрос для независимого чтения

Прочитать `SKILL.md`, паспорт, `references/order-draft.md` и профиль СДЭК. Возобновить подготовку одной позиции в выбранной форме с минимумом полного чтения страницы. Указать первые Playwright locator expressions для страны, склада, типа товара и цены, различая сохранённые адреса и гипотезы. Браузер и записи запрещены: требуется только план следующего действия по доступным ресурсам.

## Приёмка

- Сначала используются сохранённые адреса, а не повторный поиск всех полей.
- До ввода проверяются форма, единственность совпадения, подпись/тип и соответствие строки.
- При отсутствующем, неоднозначном или неверно подписанном контроле выполняется прицельный поиск; исправляется затронутый кэш.
- Видимый Select2 контрол открывается отдельно от скрытого select; поле поиска адресуется после открытия.
- Индекс строки устанавливается по живому DOM, не равен автоматически позиции draft.
- Исторические значения, оферта и цена при изменении не становятся defaults; submit не выполняется.

## Живой локальный probe

В авторизованной форме открыть две пустые строки. Проверить адреса, labels и типы контролов обеих строк, открыть/закрыть поиск категории без выбора. Для одного поля проверить поиск по label при намеренно испорченном CSS locator. Проверка не требует товарного ввода, оферты, отправки или изменения draft.
